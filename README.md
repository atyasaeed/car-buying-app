
### Prerequisites

- **Java 17+**
- **Maven 3.6+**
- **PostgreSQL 14+**

### Quick Start (3 Steps)

#### 1. Start PostgreSQL Database

- Database: `car_buying_db`
- Username: `postgres`
- Password: `postgres`

#### 2. Build the Project

mvn clean install -DskipTests
```

#### 3. Run the Application

java -jar target/car-buying-app-1.0.0.jar


**API is ready at:** `http://localhost:8080`
